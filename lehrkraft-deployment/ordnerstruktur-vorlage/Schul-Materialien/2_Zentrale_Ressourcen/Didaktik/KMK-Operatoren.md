# KMK-Operatoren für Aufgabenstellungen

Die **Kultusministerkonferenz (KMK)** hat standardisierte Operatoren definiert, die in Aufgabenstellungen verwendet werden sollten. Diese sorgen für Klarheit bei Schüler:innen und einheitliche Bewertung.

## Anforderungsbereich I: Reproduktion

| Operator | Bedeutung |
|----------|-----------|
| **nennen** | Informationen ohne Erläuterung wiedergeben |
| **aufzählen** | Mehrere Elemente ohne nähere Erklärung auflisten |
| **beschreiben** | Sachverhalte in eigenen Worten strukturiert wiedergeben |
| **zusammenfassen** | Wesentliche Aussagen komprimiert wiedergeben |
| **darstellen** | Sachverhalte strukturiert wiedergeben |

## Anforderungsbereich II: Reorganisation und Transfer

| Operator | Bedeutung |
|----------|-----------|
| **erklären** | Sachverhalte durch Kenntnisse verständlich machen |
| **erläutern** | Sachverhalte veranschaulichen, durch Beispiele konkretisieren |
| **begründen** | Aussagen durch Argumente stützen |
| **vergleichen** | Gemeinsamkeiten/Unterschiede herausarbeiten |
| **analysieren** | Systematisch untersuchen und Strukturen herausarbeiten |
| **untersuchen** | Aspekte erkennen und darstellen |
| **einordnen** | In einen größeren Zusammenhang stellen |

## Anforderungsbereich III: Reflexion und Problemlösung

| Operator | Bedeutung |
|----------|-----------|
| **beurteilen** | Zu einem Sachverhalt ein selbstständiges Urteil unter Verwendung von Fachwissen formulieren |
| **bewerten** | Eine eigene Position formulieren und argumentativ vertreten |
| **Stellung nehmen** | Eine begründete Einschätzung geben |
| **überprüfen** | Aussagen/Thesen auf Richtigkeit/Angemessenheit untersuchen |
| **entwickeln** | Lösungsansätze/Konzepte selbstständig erarbeiten |
| **entwerfen** | Planvoll einen Lösungsweg skizzieren |
| **diskutieren** | Argumente zu einer Position/These abwägen |

---

## Verwendung in Aufgaben (Beispiele)

### Anforderungsbereich I (Reproduktion):
> **Nenne** drei Bestandteile einer Pflanzenzelle.
> **Beschreibe** den Aufbau eines Vulkans.

### Anforderungsbereich II (Transfer):
> **Erkläre** den Zusammenhang zwischen Photosynthese und Zellatmung.
> **Vergleiche** die Regierungssysteme Deutschlands und der USA.

### Anforderungsbereich III (Problemlösung):
> **Beurteile** die Maßnahmen der Bundesregierung zur Klimapolitik.
> **Entwickle** ein Konzept zur Müllvermeidung in deiner Schule.

---

## Tipps für Lehrkräfte

1. **Eindeutigkeit:** Nutze nur **einen** Operator pro Teilaufgabe
2. **Progression:** Steigere die Anforderungsbereiche innerhalb einer Aufgabe
3. **Transparenz:** Erkläre Schüler:innen regelmäßig, was die Operatoren bedeuten
4. **Konsistenz:** Verwende die Operatoren einheitlich über alle Fächer hinweg
