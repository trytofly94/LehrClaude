# Präsentations-Vorlage (Master)

Diese Vorlage wird von dem Skill `mat-03-powerpoint-erstellen` als Formatierungsreferenz genutzt.

---

## Formatierungs-Richtlinien

### Schriftarten
- **Überschriften:** Arial, Calibri oder Helvetica (Sans-Serif)
- **Fließtext:** Arial, Calibri oder Helvetica
- **Größen:**
  - Titel: 36-44pt
  - Überschriften: 28-32pt
  - Stichpunkte: 20-24pt
  - Sprechernotizen: 14-16pt

### Farben
- **Hintergrund:** Weiß oder sehr helles Grau (#F5F5F5)
- **Text:** Dunkelgrau (#333333) oder Schwarz
- **Akzente:** Schul-/Fachfarben (z.B. Blau für Naturwissenschaften)
- **Hoher Kontrast:** Mind. 4.5:1 (WCAG-Standard)

### Layout-Prinzipien
1. **Weniger ist mehr:** Max. 5-7 Stichpunkte pro Folie
2. **Große Schrift:** Auch aus der letzten Reihe lesbar
3. **Whitespace:** Mind. 20% der Folie sollte leer bleiben
4. **Einheitlichkeit:** Gleiche Struktur für alle Folien desselben Typs

## Folien-Typen

### Typ 1: Titelfolie

```markdown
# [HAUPTTHEMA]
## [Untertitel/Kontext]

Klasse: [X]
Datum: [TT.MM.JJJJ]
```

**Sprechernotizen:** Begrüßung, Einstimmung auf das Thema

---

### Typ 2: Lernziele-Folie

```markdown
# Was lernst du heute?

- Lernziel 1 (kurz, prägnant)
- Lernziel 2
- Lernziel 3

**Icon-Vorschlag:** Zielscheibe, Glühbirne, Kompass
```

---

### Typ 3: Content-Folie (Text)

```markdown
# [Überschrift]

- Stichpunkt 1
- Stichpunkt 2
  - Unterpunkt 2.1
- Stichpunkt 3

**Bild-Vorschlag:** [Beschreibung relevanter Visualisierung]
```

**Regel:** Max. 5-7 Stichpunkte, max. 2 Ebenen Einrückung

---

### Typ 4: Visualisierungs-Folie

```markdown
# [Überschrift]

[Großes Bild/Diagramm/Grafik]

**Bildunterschrift:** Kurze Erklärung (1 Satz)
```

**Regel:** Bild nimmt mind. 60% der Folie ein

---

### Typ 5: Interaktions-Folie

```markdown
# ❓ Deine Meinung?

**Frage:** [Offene Frage an die Klasse]

💬 Think-Pair-Share:
1. Denke (30 Sek.)
2. Partner-Austausch (2 Min.)
3. Plenum
```

---

### Typ 6: Zusammenfassungs-Folie

```markdown
# 📌 Das Wichtigste

- Take-Away 1
- Take-Away 2
- Take-Away 3

**Merksatz:** [Kurze Quintessenz in 1 Satz]
```

---

### Typ 7: Ausblick/Hausaufgabe

```markdown
# 🏠 Hausaufgabe & Ausblick

**Für nächste Stunde:**
- Aufgabe 1
- Aufgabe 2

**Vorschau:** Nächstes Mal...
```

## Accessibility-Richtlinien

✅ **Barrierefreiheit:**
- Alt-Texte für alle Bilder
- Keine rein farbbasierte Information (z.B. "grüne = richtig")
- Hoher Kontrast (mind. 4.5:1)
- Keine blinkenden Animationen
- Untertitel bei Videos

✅ **Sprachförderung:**
- Einfache, klare Sprache
- Fachbegriffe erklären
- Visuelle Unterstützung

---

## Animationen (sparsam nutzen!)

**Empfohlene Animationen:**
- "Erscheinen" (Fade In) für Stichpunkte nacheinander
- "Wischen" für Folienwechsel

**Zu vermeiden:**
- Drehen, Zoomen, Blinken
- Zu viele Animationen pro Folie
- Geräusche

**Faustregel:** Nur animieren, wenn es didaktisch sinnvoll ist (z.B. schrittweiser Aufbau)

```markdown
**Icon:** 🎯

# Folie 3: Was ist Photosynthese?

- Pflanzen produzieren Zucker aus Licht
- Benötigt: Wasser, CO₂, Licht
- Ergebnis: Glucose, Sauerstoff

**Bild-Vorschlag:** Schematische Darstellung Blatt mit Sonnenlicht

---
```
