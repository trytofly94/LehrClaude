METACOM-SYMBOLE
===============

Legen Sie hier Ihre METACOM-Symbole ab.

METACOM ist ein lizenzpflichtiges Symbolsystem.
Bezug: https://www.metacom-symbole.de/


EMPFOHLENE ORDNUNG
==================

Sie koennen Unterordner nach Kategorien erstellen:

METACOM/
├── Aktivitaeten/     # spielen, arbeiten, lesen, ...
├── Emotionen/        # freude, trauer, wut, ...
├── Essen_Trinken/    # fruehstueck, mittagessen, trinken, ...
├── Hygiene/          # haende_waschen, zaehne_putzen, ...
├── Kommunikation/    # ja, nein, bitte, danke, ...
├── Orte/             # schule, zuhause, spielplatz, ...
├── Personen/         # lehrer, schueler, mama, papa, ...
├── Schule/           # unterricht, pause, sport, ...
├── Tagesablauf/      # aufstehen, anziehen, schlafen, ...
└── Verben/           # gehen, sitzen, essen, ...


DATEINAMEN
==========

Empfohlen: [kategorie]_[beschreibung].png

Beispiele:
- hygiene_haende_waschen.png
- emotion_freude.png
- tagesablauf_pause.png


HINWEIS
=======

Dieser Ordner ist leer bei der Installation.
Fuellen Sie ihn mit Ihren eigenen METACOM-Symbolen.
