# Material zusammenstellen und organisieren

## Zweck

Dieser Schritt orchestriert die systematische Zusammenstellung und Organisation aller erforderlichen Unterrichtsmaterialien für die geplante Unterrichtsreihe. Nach den vorherigen Schritten werden hier alle noch fehlenden Materialien identifiziert und erstellt.

Der Schritt folgt einer dreistufigen Struktur:
1. **Material-Phase 1:** Erstellung fehlender Materialien zu den Aufgaben
2. **Material-Phase 2:** Entwicklung differenzierter Hilfsmaterialien (gestufte Lernhilfen)
3. **Material-Phase 3:** Erstellung von Materialien für alle Phasen des Unterrichtsverlaufs

## Wann wird dieser Schritt durchgeführt?

Dieser Schritt wird durchgeführt, wenn:
- Die Unterrichtsverlaufspläne vollständig sind
- Alle Aufgaben und Lernkontrollen erstellt wurden
- Fehlende Materialien identifiziert und erstellt werden sollen
- Differenzierte Hilfsmaterialien für alle Lerngruppen benötigt werden

## Interaktiver Workflow (WICHTIG!)

**NIEMALS direkt Dateien erstellen ohne Abstimmung mit der Lehrkraft!**

### Phase A: Informationen sammeln
1. Stelle alle notwendigen Rückfragen
2. Warte auf Antworten der Lehrkraft
3. Bei Unklarheiten: Nachfragen, nicht annehmen

### Phase B: Iterative Erarbeitung
1. Erarbeite die Inhalte basierend auf dem Input
2. Zeige eine **Zusammenfassung** im Chat (nicht den vollen Text)
3. Frage explizit: "Passt diese Richtung? Haben Sie Änderungswünsche?"
4. Passe an basierend auf Feedback
5. Wiederhole bis die Lehrkraft zufrieden ist

### Phase C: Abschluss
1. Zeige die **finale Zusammenfassung** im Chat
2. Frage: "Sind Sie mit diesem Ergebnis zufrieden?"
3. **Erst nach Zustimmung:** "Soll ich das Ergebnis als TXT-Datei speichern?"
4. Speichere nur auf expliziten Wunsch

### VERBOTEN:
- Direkt TXT-Dateien erstellen ohne vorherige Abstimmung
- Annehmen, dass die Lehrkraft zufrieden ist
- Inhalte generieren ohne Rückfragen

## Ablauf: Drei-Phasen-Materialbeschaffung

### Phase 1: Fehlende Materialien zu den Aufgaben

**Phase A: Informationen sammeln**
1. Sachtext-Aufgaben prüfen und Rückfragen klären
2. Für jede Aufgabe notwendige Materialien identifizieren
3. Bei Unklarheiten nachfragen, nicht annehmen

**Phase B: Iterative Erarbeitung**
1. Materialien basierend auf Input erstellen:
   - Alle fehlenden Sachtexte
   - Zusätzliche erforderliche Materialien
   - Materialien altersgerecht formulieren
2. **Zusammenfassung** der erstellten Materialien im Chat zeigen (nicht vollständigen Text)
3. Frage: "Passt diese Richtung? Haben Sie Änderungswünsche?"
4. Anpassungen vornehmen basierend auf Feedback
5. Wiederholung bis Lehrkraft zufrieden

**Phase C: Abschluss**
1. Finale Zusammenfassung präsentieren
2. Zufriedenheit prüfen: "Sind Sie mit diesem Ergebnis zufrieden?"
3. Export anbieten: "Soll ich das Ergebnis als TXT-Datei speichern?"
4. Nur bei Zustimmung: TXT-Datei speichern

**Einschränkungen:**
- **Korrektheit:** Nur verifizierte Daten verwenden
- **Grafiken/Diagramme:** Statt Grafiken kurze Hinweise geben (z.B. "Grafik Körperbau Grashüpfer")
- **Sprachliche Angemessenheit:** Texte altersgerecht formulieren
- **Formatierung:** Fließtexte übersichtlich formatieren

### Phase 2: Differenzierte Hilfsmaterialien (Gestufte Lernhilfen)

**Ziel:** Zu allen Aufgaben aller Differenzierungsniveaus (Basisstufe, Unterstützungsstufe, Erweiterungsstufe) entsprechende gestufte Lernhilfen erstellen.

**Phase A: Informationen sammeln**
1. Alle Aufgaben der drei Differenzierungsniveaus identifizieren
2. Potenzielle Schwierigkeiten für jede Aufgabe klären
3. Bei Unklarheiten: Rückfragen zu spezifischen Lernbarrieren

**Phase B: Iterative Erarbeitung**
1. Gestufte Lernhilfen erstellen:
   - Hauptaufgabe in kleinere Teilschritte zerlegen
   - Schwierigkeiten identifizieren
   - Impulse formulieren
   - Teilantworten erstellen
2. **Zusammenfassung** der Lernhilfen im Chat zeigen (nicht vollständige Texte)
3. Frage: "Passt diese Richtung? Haben Sie Änderungswünsche?"
4. Anpassungen basierend auf Feedback
5. Wiederholung bis Lehrkraft zufrieden

**Phase C: Abschluss**
1. Finale Zusammenfassung präsentieren
2. Zufriedenheit prüfen: "Sind Sie mit diesem Ergebnis zufrieden?"
3. Export anbieten: "Soll ich das Ergebnis als TXT-Datei speichern?"
4. Nur bei Zustimmung: TXT-Datei speichern

**Gliederung:** Zuerst Aufgabe, dann gestufte Lernhilfe angeben

### Phase 3: Weitere Materialien aller Unterrichtsphasen

**Ziel:** Alle fehlenden Materialien für alle Phasen der Unterrichtsverlaufspläne erstellen.

**Phase A: Informationen sammeln**
1. Alle Unterrichtsverlaufspläne durchgehen
2. Für jede Phase klären, welche Materialien benötigt werden
3. Typische Materialien pro Phase identifizieren:
   - **Einstieg:** Anekdoten, Fakten, provokative Fragen
   - **Erarbeitung:** Sachtexte, Arbeitsaufträge, Experimente
   - **Sicherung:** Zusammenfassungen, Sicherungsaufträge
   - **Abschluss:** Reflexionsfragen, Transferaufgaben

**Phase B: Iterative Erarbeitung**
1. Fehlende Materialien erstellen und unterrichtsverwendbar formatieren
2. **Zusammenfassung** der Materialien im Chat zeigen (nicht vollständige Texte)
3. Frage: "Passt diese Richtung? Haben Sie Änderungswünsche?"
4. Anpassungen basierend auf Feedback
5. Wiederholung bis Lehrkraft zufrieden

**Phase C: Abschluss**
1. Finale Zusammenfassung präsentieren
2. Zufriedenheit prüfen: "Sind Sie mit diesem Ergebnis zufrieden?"
3. Export anbieten: "Soll ich das Ergebnis als TXT-Datei speichern?"
4. Nur bei Zustimmung: TXT-Datei speichern

## Qualitätssicherung

Alle erstellten Materialien müssen folgende Kriterien erfüllen:
- **Sachliche Korrektheit:** Alle Inhalte wissenschaftlich korrekt
- **Altersgerechte Sprache:** Angepasst an die Zielgruppe
- **Aufgabenbezug:** Notwendig zur Bearbeitung der Aufgaben
- **Differenzierung:** Unterschiedliche Materialien für unterschiedliche Lerngruppen
- **Praktische Einsetzbarkeit:** Unmittelbar im Unterricht verwendbar
- **Konsistenz:** Aufbauend auf bisherigen Planungsergebnissen
