# Schul-KI

## Unterrichtsplanung mit KI - Lernmodul

Dieses Repository enthält eine umfassende Dokumentation eines Lernmoduls zur KI-gestützten Unterrichtsplanung.

### Inhalt

- **Unterrichtsplanung_mit_KI_Lernmodul_Zusammenfassung.md**: Strukturierte Zusammenfassung mit technischem Hintergrund und Prompt-Übersicht
- **Lernmodul_Vollstaendige_Inhalte.md**: Vollständige 1:1 Kopie aller Modulinhalte

### Autor des Originalmoduls

Christopher Zimmermann (Universität zu Köln)

### Zweck

Dokumentation und Archivierung des Prompt-Katalogs zur Unterstützung von Lehrkräften bei der Unterrichtsplanung mit Large Language Models.
